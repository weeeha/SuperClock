> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the `ai-face` kiosk app with its full foundation (vendored avatar pages, design registry, canonical state, adapter contract, state sources, frame guard) and the 25 designs of the shared abstract engine (core-eyes 16, luminous-faces 7, assistant-iris 1, fractal-presence 1).

**Architecture:** A sync script copies an allowlisted subset of AI-Avatars (pinned by its git SHA) into `public/avatars/`. The app renders one design's original page in a same-origin, pointer-transparent iframe, hides the gallery chrome with an injected stylesheet, and drives the page's own `window.abstractPreview` API through a family adapter. State comes from an `AvatarStateSource` (demo or fixed in SP1), night forces `sleeping`, and a frame guard steps a struggling design down to half resolution, then to a paused pose.

**Tech Stack:** React 19, TypeScript (`verbatimModuleSyntax`, `erasableSyntaxOnly`), zod 4, Vitest 4 (+ jsdom per file, @testing-library/react 16), Tailwind v4, tsx for scripts.

**Spec:** `docs/superpowers/specs/2026-10-09-ai-face-design.md` (approved 2026-10-09, decision 8.1 = A). Read it before Task 1.

## Review Focus

1. **A design page that never becomes ready** (404, script error, API missing, URL param ignored so the wrong character shows): a person expects an honest "Face unavailable" tell, never an endless black disc. Pinned in Task 6 (timeout test) and Task 4 (wrong-character returns `null`).
2. **The kiosk is hidden or the iframe page is paused** (`document.hidden`, reduced motion, app inactive): the frame counter stalls, and a person expects the face to resume normally, not to be permanently degraded to "Paused to keep the clock cool". Pinned in Task 5 (`idle` samples reset the window) and Task 6 (parent `document.hidden` marks the sample idle).
3. **Swiping away and back repeatedly within 60 s**: a person expects one iframe, no leaked intervals, and the face resuming where it was. Pinned in Task 6 (fake-timer test: inactive → active before 60 s keeps the same iframe; after 60 s it unmounts and remounts on return).
4. **A stored config naming a design or value this build does not know** (an older or newer admin): a person expects the face to fall back to the default design rather than a crash. Pinned in Task 2 (schema parse of an unknown id fails; app falls back to defaults, the house `safeParse` pattern) and Task 6.
5. **The night window starts or ends while the face is showing**: a person expects it to fall asleep at night and come back to its configured activity in the morning. Pinned in Task 3 (`applyNight` both directions).

```ts
// What SuperClock vendors from weeeha/AI-Avatars, derived from the design
// registry so a new design cannot ship without its files (and vice versa).
// Anything else that appears upstream in a watched directory fails the sync:
// a new asset is a conscious decision, not a silent payload increase.
import { AVATAR_DESIGNS } from '../../src/shared/ai-face-designs';

const families = [...new Set(AVATAR_DESIGNS.map((d) => d.family))];

export const ALLOWLIST: string[] = [
  'assets/preview.css',
  'assets/preview-state.js',
  'assets/abstract-performance.css',
  'assets/abstract-performance.js',
  ...families.flatMap((f) => [`characters/${f}/index.html`, `characters/${f}/index.css`, `characters/${f}/index.js`]),
  ...AVATAR_DESIGNS.map((d) => `assets/abstract/${d.character}.png`),
];

export const WATCHED_DIRS: string[] = [...families.map((f) => `characters/${f}`), 'assets/abstract'];

const IGNORED = [/\.gif$/, /(^|\/)README\.md$/, /\/(sources|concepts|frames|animation-sources)\//];

export function planSync(watchedFiles: string[], allowlist: string[]) {
  const present = new Set(watchedFiles);
  const allowed = new Set(allowlist);
  return {
    copy: allowlist.filter((f) => present.has(f)),
    unknown: watchedFiles.filter((f) => !allowed.has(f) && !IGNORED.some((re) => re.test(f))),
    missing: allowlist.filter((f) => !present.has(f)),
  };
}
```

`scripts/sync-avatars.ts`:

```ts
// npm run sync:avatars -- <path to a clean AI-Avatars checkout>
// Copies the allowlisted files into public/avatars/ and records the source SHA.
import { execFileSync } from 'node:child_process';
import { cpSync, mkdirSync, readdirSync, rmSync, statSync, writeFileSync, existsSync } from 'node:fs';
import { dirname, join, relative } from 'node:path';
import { fileURLToPath } from 'node:url';
import { ALLOWLIST, WATCHED_DIRS, planSync } from './lib/avatar-sync';

const root = join(dirname(fileURLToPath(import.meta.url)), '..');
const src = process.argv[2];
if (!src || !existsSync(join(src, 'catalog.json'))) {
  console.error('usage: npm run sync:avatars -- <path to an AI-Avatars checkout>');
  process.exit(1);
}
const git = (...args: string[]) => execFileSync('git', ['-C', src, ...args], { encoding: 'utf8' }).trim();
if (git('status', '--porcelain')) {
  console.error('AI-Avatars checkout has local changes; sync only from a committed SHA.');
  process.exit(1);
}
const sha = git('rev-parse', 'HEAD');

const walk = (dir: string): string[] =>
  readdirSync(dir).flatMap((name) => {
    const full = join(dir, name);
    return statSync(full).isDirectory() ? walk(full) : [relative(src, full)];
  });
const watched = [
  ...WATCHED_DIRS.flatMap((d) => (existsSync(join(src, d)) ? walk(join(src, d)) : [])),
  ...ALLOWLIST.filter((f) => !WATCHED_DIRS.some((d) => f.startsWith(`${d}/`)) && existsSync(join(src, f))),
];
const plan = planSync(watched, ALLOWLIST);
if (plan.unknown.length || plan.missing.length) {
  if (plan.unknown.length) console.error('Not on the allowlist (scripts/lib/avatar-sync.ts):\n  ' + plan.unknown.join('\n  '));
  if (plan.missing.length) console.error('Allowlisted but missing upstream:\n  ' + plan.missing.join('\n  '));
  process.exit(1);
}

const out = join(root, 'public', 'avatars');
rmSync(out, { recursive: true, force: true });
for (const f of plan.copy) {
  mkdirSync(dirname(join(out, f)), { recursive: true });
  cpSync(join(src, f), join(out, f));
}
writeFileSync(join(out, 'VERSION'), `${sha}\n${new Date().toISOString().slice(0, 10)}\n`);
console.log(`synced ${plan.copy.length} files from AI-Avatars ${sha.slice(0, 7)}`);
```

import type { AvatarActivity, AvatarExpression } from '../../../shared/ai-face-designs';
import type { AvatarState, AvatarStateSource } from './types';

// One pass through a working session. Durations give each family time for its
// entry, hold and exit motion. Operational conditions (offline, permission
// denied) are never part of a demo: a demo must not claim a live failure.
export const DEMO_STEPS: readonly { activity: AvatarActivity; ms: number }[] = [
  { activity: 'starting', ms: 3000 },
  { activity: 'idle', ms: 8000 },
  { activity: 'listening', ms: 5000 },
  { activity: 'thinking', ms: 6000 },
  { activity: 'researching', ms: 6000 },
  { activity: 'working', ms: 8000 },
  { activity: 'answering', ms: 7000 },
  { activity: 'waiting', ms: 5000 },
  { activity: 'needs-input', ms: 5000 },
  { activity: 'complete', ms: 4000 },
  { activity: 'idle', ms: 6000 },
  { activity: 'error', ms: 4000 },
  { activity: 'sleeping', ms: 8000 },
];
export const DEMO_EXPRESSIONS: readonly AvatarExpression[] = [
  'neutral', 'curious', 'happy', 'playful', 'neutral', 'concerned', 'surprised', 'confused',
];
export const DEMO_EXPRESSION_MS = 15_000;

const CYCLE_MS = DEMO_STEPS.reduce((t, s) => t + s.ms, 0);

export function demoStateAt(elapsedMs: number): AvatarState {
  let t = ((elapsedMs % CYCLE_MS) + CYCLE_MS) % CYCLE_MS;
  let activity = DEMO_STEPS[0].activity;
  for (const step of DEMO_STEPS) {
    if (t < step.ms) { activity = step.activity; break; }
    t -= step.ms;
  }
  const expression = DEMO_EXPRESSIONS[Math.floor(elapsedMs / DEMO_EXPRESSION_MS) % DEMO_EXPRESSIONS.length];
  return { activity, expression };
}

export function createDemoSource(now: () => number = () => Date.now()): AvatarStateSource {
  return {
    initial: demoStateAt(0),
    subscribe(cb) {
      const start = now();
      let last = demoStateAt(0);
      cb(last);
      const id = setInterval(() => {
        const next = demoStateAt(now() - start);
        if (next.activity !== last.activity || next.expression !== last.expression) {
          last = next;
          cb(next);
        }
      }, 500);
      return () => clearInterval(id);
    },
  };
}

import {
  AVATAR_PAGE,
  type AvatarActivity,
  type AvatarDesign,
  type AvatarExpression,
} from '../../../shared/ai-face-designs';
import type { AvatarState } from '../sources/types';
import type { FamilyAdapter } from './types';

// AI-Avatars' shared abstract engine (assets/abstract-performance.js) behind
// core-eyes, luminous-faces, assistant-iris and fractal-presence. It already
// speaks the canonical vocabulary, so both maps are identities, written out so
// the coverage test can hold them and SP2 families can differ.
interface AbstractApi {
  getState(): { character: string; paused: boolean; reducedMotion: boolean; frame: number };
  setState(activity: string): void;
  setEmotion(emotion: string): void;
  setPaused(paused: boolean): void;
}

const activityMap: Record<AvatarActivity, string> = {
  idle: 'idle', starting: 'starting', listening: 'listening', thinking: 'thinking',
  researching: 'researching', working: 'working', answering: 'answering', waiting: 'waiting',
  'needs-input': 'needs-input', complete: 'complete', error: 'error', sleeping: 'sleeping',
};
const expressionMap: Record<AvatarExpression, string> = {
  neutral: 'neutral', happy: 'happy', curious: 'curious', surprised: 'surprised',
  confused: 'confused', concerned: 'concerned', playful: 'playful',
};

const kioskCss = `
html, body { margin: 0; width: 100%; height: 100%; overflow: hidden; background: black; }
.page { max-width: none !important; margin: 0 !important; padding: 0 !important; }
.page-nav, .abstract-controls { display: none !important; }
.abstract-stage { max-width: none !important; width: 100vmin !important; height: 100vmin !important; margin: 0 !important; }
`;

export const abstractAdapter: FamilyAdapter = {
  pageUrl: (d: AvatarDesign) => `${AVATAR_PAGE[d.family]}?character=${encodeURIComponent(d.character)}`,
  kioskCss,
  activityMap,
  expressionMap,
  attach(win, design) {
    const api = (win as unknown as { abstractPreview?: AbstractApi }).abstractPreview;
    if (!api || api.getState().character !== design.character) return null;
    let last: AvatarState | null = null;
    return {
      apply(s) {
        if (last?.activity !== s.activity) api.setState(activityMap[s.activity]);
        if (last?.expression !== s.expression) api.setEmotion(expressionMap[s.expression]);
        last = s;
      },
      setPaused: (p) => api.setPaused(p),
      setMuted: () => {},
      sample: () => {
        const st = api.getState();
        return { frame: st.frame, idle: st.paused || st.reducedMotion };
      },
      destroy: () => api.setPaused(true),
    };
  },
};

import type { AvatarSample } from './adapters/types';

// Spec 3.6 (decision 8.1 = A): every design is offered everywhere; one that
// cannot keep up steps down to half resolution, then pauses with a tell.
// Pure, so the thresholds are tested without a renderer.
export type GuardLevel = 'full' | 'half' | 'paused';

export interface GuardState {
  level: GuardLevel;
  fps: number[];
  lastFrame: number | null;
  lastAt: number | null;
  settleUntil: number;
}

export const GUARD = { minFps: 24, window: 5, settleMs: 10_000 } as const;

export function initialGuard(at: number): GuardState {
  return { level: 'full', fps: [], lastFrame: null, lastAt: null, settleUntil: at + GUARD.settleMs };
}

const median = (xs: number[]) => {
  const s = [...xs].sort((a, b) => a - b);
  return s.length % 2 ? s[(s.length - 1) / 2] : (s[s.length / 2 - 1] + s[s.length / 2]) / 2;
};

export function stepGuard(g: GuardState, s: AvatarSample, at: number): GuardState {
  if (g.level === 'paused') return g;
  if (s.idle) return { ...g, fps: [], lastFrame: null, lastAt: null };
  if (g.lastFrame === null || g.lastAt === null || s.frame < g.lastFrame || at <= g.lastAt) {
    return { ...g, lastFrame: s.frame, lastAt: at };
  }
  const fps = [...g.fps, (s.frame - g.lastFrame) / ((at - g.lastAt) / 1000)].slice(-GUARD.window);
  const next = { ...g, fps, lastFrame: s.frame, lastAt: at };
  if (at < g.settleUntil || fps.length < GUARD.window || median(fps) >= GUARD.minFps) return next;
  return {
    ...next,
    level: g.level === 'full' ? 'half' : 'paused',
    fps: [],
    settleUntil: at + GUARD.settleMs,
  };
}

import { useEffect, useRef, useState } from 'react';
import type { AvatarDesign } from '../../shared/ai-face-designs';
import { adapterFor } from './adapters';
import type { AvatarController, FamilyAdapter } from './adapters/types';
import { initialGuard, stepGuard, type GuardLevel } from './frame-guard';
import type { AvatarState } from './sources/types';

export const UNMOUNT_AFTER_MS = 60_000;
export const ATTACH_TIMEOUT_MS = 5_000;
const ATTACH_POLL_MS = 100;

interface Props {
  design: AvatarDesign;
  state: AvatarState;
  active: boolean;
  adapter?: FamilyAdapter;
}

// Keeps the page mounted through a quick swipe away and back; frees GL
// contexts and decoders after a minute in the background (KIO-1).
export default function AvatarFrame({ design, state, active, adapter }: Props) {
  const [mounted, setMounted] = useState(active);
  if (active && !mounted) setMounted(true); // adjust state during render

  useEffect(() => {
    if (active) return;
    const id = setTimeout(() => setMounted(false), UNMOUNT_AFTER_MS);
    return () => clearTimeout(id);
  }, [active]);

  if (!mounted) return null;
  return <Page key={design.id} design={design} state={state} active={active} adapter={adapter ?? adapterFor(design)} />;
}

function Page({ design, state, active, adapter }: Required<Props>) {
  const iframeRef = useRef<HTMLIFrameElement>(null);
  const controllerRef = useRef<AvatarController | null>(null);
  const [status, setStatus] = useState<'loading' | 'ready' | 'unavailable'>('loading');
  const [level, setLevel] = useState<GuardLevel>('full');

  // Attach: inject the kiosk stylesheet, then poll for the page API. jsdom and
  // some browsers fire load for about:blank first; attach only once.
  const onLoad = () => {
    if (controllerRef.current || pollRef.current) return;
    const iframe = iframeRef.current;
    const win = iframe?.contentWindow;
    const doc = iframe?.contentDocument;
    if (!win || !doc) return setStatus('unavailable');
    const style = doc.createElement('style');
    style.textContent = adapter.kioskCss;
    doc.head.append(style);
    const started = Date.now();
    const poll = setInterval(() => {
      const c = adapter.attach(win, design);
      if (c) {
        clearInterval(poll);
        controllerRef.current = c;
        setStatus('ready');
      } else if (Date.now() - started >= ATTACH_TIMEOUT_MS) {
        clearInterval(poll);
        setStatus('unavailable');
      }
    }, ATTACH_POLL_MS);
    pollRef.current = poll;
  };
  const pollRef = useRef<ReturnType<typeof setInterval> | null>(null);

  useEffect(() => () => {
    if (pollRef.current) clearInterval(pollRef.current);
    controllerRef.current?.destroy();
    controllerRef.current = null;
  }, []);

  useEffect(() => {
    if (status === 'ready') controllerRef.current?.apply(state);
  }, [state, status]);

  useEffect(() => {
    if (status === 'ready') controllerRef.current?.setPaused(!active || level === 'paused');
  }, [active, status, level]);

  // Frame guard, 1 Hz, only while active and attached.
  useEffect(() => {
    if (status !== 'ready' || !active || level === 'paused') return;
    let guard = { ...initialGuard(Date.now()), level };
    const id = setInterval(() => {
      const c = controllerRef.current;
      if (!c) return;
      const s = c.sample();
      guard = stepGuard(guard, { frame: s.frame, idle: s.idle || document.hidden }, Date.now());
      if (guard.level !== level) setLevel(guard.level);
    }, 1000);
    return () => clearInterval(id);
  }, [status, active, level]);

  const half = level !== 'full';
  return (
    <div className="absolute inset-0 overflow-hidden bg-black">
      <iframe
        ref={iframeRef}
        src={adapter.pageUrl(design)}
        title={design.name}
        onLoad={onLoad}
        className="absolute left-0 top-0 border-0 transition-opacity duration-300"
        style={{
          pointerEvents: 'none',
          width: half ? '50%' : '100%',
          height: half ? '50%' : '100%',
          transform: half ? 'scale(2)' : undefined,
          transformOrigin: '0 0',
          opacity: status === 'ready' ? 1 : 0,
        }}
      />
      {status === 'unavailable' && <Tell>Face unavailable</Tell>}
      {level === 'paused' && <Tell>Paused to keep the clock cool</Tell>}
    </div>
  );
}

function Tell({ children }: { children: string }) {
  return (
    <p className="absolute inset-x-0 bottom-[22%] text-center text-[2.4vmin] text-(--face-ink-muted)">{children}</p>
  );
}

const noopSubscribe = () => () => {};

export default function AiFaceApp({ isActive, config }: AppProps) {
  const parsed = aiFaceAppSchema.safeParse(config ?? {});
  const cfg = parsed.success ? parsed.data : aiFaceAppSchema.parse({});
  const design = findDesign(cfg.design) ?? AVATAR_DESIGNS[0];

  const store = useMemo(
    () => toExternalStore(sourceFor({ source: cfg.source, activity: cfg.activity, expression: cfg.expression })),
    [cfg.source, cfg.activity, cfg.expression],
  );
  // Subscribing starts the demo interval, so only an active face subscribes.
  const raw = useSyncExternalStore(isActive ? store.subscribe : noopSubscribe, store.getSnapshot);
  const state = applyNight(raw, useIsNight(), cfg.sleepAtNight);

      <AvatarFrame design={design} state={state} active={isActive} />
      {cfg.showTime && <TimeLabel active={isActive} />}
      {cfg.source === 'demo' && (
        <span className="absolute inset-x-0 top-[12%] text-center text-[2vmin] text-(--face-ink-muted)">Demo</span>
      )}
    </div>
  );
}

const fmt = (d: Date) => d.toLocaleTimeString([], { hour: 'numeric', minute: '2-digit' });

function TimeLabel({ active }: { active: boolean }) {
  const [now, setNow] = useState(() => new Date());
  useEffect(() => {
    if (!active) return;
    let id: ReturnType<typeof setTimeout>;
    const tick = () => {
      setNow(new Date());
      id = setTimeout(tick, 60_000 - (Date.now() % 60_000) + 25);
    };
    id = setTimeout(tick, 60_000 - (Date.now() % 60_000) + 25);
    return () => clearTimeout(id);
  }, [active]);
  return (
    <span
      data-testid="ai-face-time"
      className="absolute inset-x-0 bottom-[10%] text-center text-[3.2vmin] tabular-nums text-(--face-ink)"
    >
      {fmt(now)}
    </span>
  );
