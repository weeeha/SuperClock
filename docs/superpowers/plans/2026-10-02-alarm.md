# Alarm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Alarm app and the six small core additions it needs (ring length, brightness hold, panel wake, lead window, lead view, brightness ramp), plus the server's loopback wake route.

**Architecture:** The core alert store gains optional `ringMs`, `bright` and `leadMs` on each alert and a persisted `leading` flag; the scheduler sets it at each lead boundary. `AlertLayer` holds the brightness lease for bright alerts, asks the clock's own server to wake the panel, and shows an app's registered lead view during the lead window; `apply-settings` ramps the night filter out with a CSS transition. Alarm keeps its alarms in a persisted module store, a boot-time subscription keeps one core alert per enabled alarm at its next occurrence, and the screens follow Nick's board frames 1 to 8.

**Tech Stack:** React 19, TypeScript (`verbatimModuleSyntax`, `erasableSyntaxOnly`), zustand 5, zod, Tailwind v4, Express 5, Vitest 4 + @testing-library/react (jsdom opt-in per file), lucide-react.

**Spec:** `docs/superpowers/specs/2026-10-02-alarm-design.md` (and, for the alert layer it extends, `docs/superpowers/specs/2026-10-02-alerts-and-timer-design.md`). Board: Designs page section Alarm `111:957`.

## Plan rulings (where this plan departs from the spec's wording)

- **Lead state is derived, not a `lead` plan kind.** The spec has `planNext` return `{ kind: 'lead' }` and the scheduler set `leading` once. Here the scheduler recomputes `leadCandidate(scheduled, now)` on every run and sets `leading` to it (or null). Same behaviour on the happy path, and it also clears a lead whose alarm was edited to a later time, which the spec's version would leave stuck until fire. `planNext` still treats each lead start as a boundary.
- **Disabling cancels a snooze in the UI action, not in the sync.** The spec says disabling an alarm also cancels its pending snooze. A once-alarm disables itself the moment it fires, so a sync-side rule would kill the snooze the sleeper just set. The switch (`toggleAlarm`) and Delete call `cancelSnooze`; the sync cancels snoozes only for deleted alarms.
- **No pager dots on resting/list.** `.claude/rules/gestures-and-navigation.md` says multi-view apps show Habits-style dots by convention, but Nick's frames 1 and 2 draw none and the spec lists none. Flagged in the agent log; not added.
- **Grid tile** goes into the third AppGrid column (3 tiles → 4), following how Todo, Countdown and Timer were slotted in (a short column filled, the Figma column shape kept).

```ts
// What is scheduled to interrupt the kiosk, and what is interrupting it now.
// Persisted so an alert survives app unmounts, Chromium's 6-hourly restart and
// deploys (specs docs/superpowers/specs/2026-10-02-alerts-and-timer-design.md
// and 2026-10-02-alarm-design.md).
import { create } from 'zustand';
import { z } from 'zod';
import { useNavigation } from '../navigation';
import { getLeadView } from './views';

export interface ScheduledAlert {
  id: string;
  appId: string;
  firesAt: number;
  sound: boolean;
  payload: Record<string, unknown>;
  /** How long it rings before settling; RING_MS when absent. */
  ringMs?: number;
  /** Hold full brightness while ringing, over night dimming. */
  bright?: boolean;
  /** A lead window before firesAt: panel wake, brightness ramp, the app's lead view. */
  leadMs?: number;
}

export interface RingingAlert extends ScheduledAlert {
  firedAt: number;
  /** Flipped by the scheduler once its ring length has passed: pulse and chime stop. */
  settled: boolean;
}

export interface AlertState {
  scheduled: ScheduledAlert[];
  ringing: RingingAlert | null;
  /** Id of the scheduled alert inside its lead window, set by the scheduler. */
  leading: string | null;
  /** The lead view was tapped away; resets whenever `leading` changes. */
  leadHidden: boolean;
  schedule: (alert: ScheduledAlert) => void;
  cancel: (id: string) => void;
  fire: (id: string, firedAt: number) => void;
  settle: () => void;
  dismiss: () => void;
  setLeading: (id: string | null) => void;
  hideLead: () => void;
}

export const RING_MS = 5 * 60_000;
export const ALERTS_STORAGE_KEY = 'superclock:alerts:v1';

const scheduledSchema = z.object({
  id: z.string().min(1),
  appId: z.string().min(1),
  firesAt: z.number(),
  sound: z.boolean(),
  payload: z.record(z.string(), z.unknown()),
  ringMs: z.number().positive().optional(),
  bright: z.boolean().optional(),
  leadMs: z.number().positive().optional(),
});
const fileSchema = z.object({
  scheduled: z.array(scheduledSchema),
  ringing: scheduledSchema.extend({ firedAt: z.number(), settled: z.boolean() }).nullable(),
  // Absent in files written before the lead window existed.
  leading: z.string().nullable().default(null),
  leadHidden: z.boolean().default(false),
});

type StorageLike = Pick<Storage, 'getItem' | 'setItem'>;
type Persisted = Pick<AlertState, 'scheduled' | 'ringing' | 'leading' | 'leadHidden'>;

function load(storage: StorageLike | null): Persisted {
  const empty: Persisted = { scheduled: [], ringing: null, leading: null, leadHidden: false };
  if (!storage) return empty;
  try {
    const raw = storage.getItem(ALERTS_STORAGE_KEY);
    if (!raw) return empty;
    const parsed = fileSchema.safeParse(JSON.parse(raw));
    // Losing an alert beats a kiosk that crashes on every boot.
    return parsed.success ? parsed.data : empty;
  } catch {
    return empty;
  }
}

/** storage is injectable so the store round-trips under test without a DOM. */
export function createAlertStore(storage: StorageLike | null) {
  const store = create<AlertState>()((set, get) => {
    const unlead = (id: string) => (get().leading === id ? { leading: null, leadHidden: false } : {});
    return {
      ...load(storage),
      schedule: (alert) =>
        set({ scheduled: [...get().scheduled.filter((a) => a.id !== alert.id), alert] }),
      cancel: (id) => {
        const { scheduled } = get();
        if (!scheduled.some((a) => a.id === id)) return;
        set({ scheduled: scheduled.filter((a) => a.id !== id), ...unlead(id) });
      },
      fire: (id, firedAt) => {
        const { scheduled, ringing } = get();
        if (ringing) return; // one at a time; the scheduler fires the next after dismiss
        const alert = scheduled.find((a) => a.id === id);
        if (!alert) return;
        set({
          scheduled: scheduled.filter((a) => a.id !== id),
          ringing: { ...alert, firedAt, settled: false },
          ...unlead(id),
        });
      },
      settle: () => {
        const { ringing } = get();
        if (ringing && !ringing.settled) set({ ringing: { ...ringing, settled: true } });
      },
      dismiss: () => {
        if (!get().ringing) return;
        set({ ringing: null });
        // Playlist rotation resumes after its usual post-gesture cooldown.
        useNavigation.getState().noteUserGesture();
      },
      setLeading: (id) => {
        if (get().leading !== id) set({ leading: id, leadHidden: false });
      },
      hideLead: () => {
        const { leading, leadHidden } = get();
        if (leading && !leadHidden) set({ leadHidden: true });
      },
    };
  });
  store.subscribe((s) => {
    if (!storage) return;
    try {
      storage.setItem(
        ALERTS_STORAGE_KEY,
        JSON.stringify({ scheduled: s.scheduled, ringing: s.ringing, leading: s.leading, leadHidden: s.leadHidden }),
      );
    } catch {
      // Full or blocked storage: the alert still rings this session.
    }
  });
  return store;
}

const defaultStorage =
  typeof window !== 'undefined' && window.localStorage ? window.localStorage : null;

export const useAlerts = createAlertStore(defaultStorage);

export function ringPhase(alert: RingingAlert): 'ringing' | 'settled' {
  return alert.settled ? 'settled' : 'ringing';
}

/** True while an alert rings, or while an app's lead view is on screen. */
export function selectScreenHeld(
  s: Pick<AlertState, 'scheduled' | 'ringing' | 'leading' | 'leadHidden'>,
): boolean {
  if (s.ringing) return true;
  if (!s.leading || s.leadHidden) return false;
  const alert = s.scheduled.find((a) => a.id === s.leading);
  return Boolean(alert && getLeadView(alert.appId));
}

/** Non-hook read for the shell's plain functions (gestures, idle, playlist). */
export function isScreenHeld(): boolean {
  return selectScreenHeld(useAlerts.getState());
}
```

```ts
// One clock for every alert boundary: when the earliest scheduled alert fires,
// when a lead window starts, and when a ringing alert settles. The board's
// deliberate exception to "only tick while active", kept to a single timeout.
import { useEffect, useState } from 'react';
import { RING_MS, useAlerts, type RingingAlert, type ScheduledAlert } from './alert-store';

/** setTimeout's ceiling; longer waits simply re-plan when it elapses. */
export const MAX_TIMEOUT_MS = 2 ** 31 - 1;

export type Plan =
  | { kind: 'idle' }
  | { kind: 'fire'; alert: ScheduledAlert }
  | { kind: 'settle' }
  | { kind: 'wait'; ms: number };

/** The earliest scheduled alert whose lead window contains `now`. */
export function leadCandidate(scheduled: ScheduledAlert[], now: number): ScheduledAlert | null {
  let best: ScheduledAlert | null = null;
  for (const a of scheduled) {
    if (!a.leadMs || a.firesAt <= now || a.firesAt - a.leadMs > now) continue;
    if (!best || a.firesAt < best.firesAt) best = a;
  }
  return best;
}

export function planNext(scheduled: ScheduledAlert[], ringing: RingingAlert | null, now: number): Plan {
  if (ringing) {
    if (ringing.settled) return { kind: 'idle' }; // the queue waits for dismiss
    const settleAt = ringing.firedAt + (ringing.ringMs ?? RING_MS);
    return settleAt <= now ? { kind: 'settle' } : { kind: 'wait', ms: Math.min(settleAt - now, MAX_TIMEOUT_MS) };
  }
  if (scheduled.length === 0) return { kind: 'idle' };
  const earliest = scheduled.reduce((x, y) => (y.firesAt < x.firesAt ? y : x));
  if (earliest.firesAt <= now) return { kind: 'fire', alert: earliest };
  // The next boundary is the earliest fire time or lead start still ahead.
  let next = earliest.firesAt;
  for (const a of scheduled) {
    if (!a.leadMs) continue;
    const leadStart = a.firesAt - a.leadMs;
    if (leadStart > now && leadStart < next) next = leadStart;
  }
  return { kind: 'wait', ms: Math.min(next - now, MAX_TIMEOUT_MS) };
}

/** Mount once, in App. */
export function useAlertScheduler(): void {
  const scheduled = useAlerts((s) => s.scheduled);
  const ringing = useAlerts((s) => s.ringing);
  const [wake, setWake] = useState(0);

  useEffect(() => {
    const now = Date.now();
    const store = useAlerts.getState();
    const lead = ringing ? null : leadCandidate(scheduled, now);
    const leadId = lead ? lead.id : null;
    if (leadId !== store.leading) store.setLeading(leadId);

    const plan = planNext(scheduled, ringing, now);
    if (plan.kind === 'fire') {
      // Its true firedAt, so an alert that came due during a restart rings only
      // for what is left of its window.
      store.fire(plan.alert.id, plan.alert.firesAt);
      return;
    }
    if (plan.kind === 'settle') {
      store.settle();
      return;
    }
    if (plan.kind === 'idle') return;
    const id = setTimeout(() => setWake((w) => w + 1), plan.ms);
    return () => clearTimeout(id);
  }, [scheduled, ringing, wake]);

  useEffect(() => {
    const onVisible = () => {
      if (!document.hidden) setWake((w) => w + 1);
    };
    document.addEventListener('visibilitychange', onVisible);
    return () => document.removeEventListener('visibilitychange', onVisible);
  }, []);
}
```

```tsx
      alert: ringing,
      phase: ringPhase(ringing),
      dismiss,
    });

      </div>
```

```ts
// Geometry for a ring dial on the round display: the band that claims drags
// runs from 60% of the radius to the inner edge of the arc-zone ring, so the
// outer arcs keep their grammar and a swipe nearer the centre still switches
// apps. Used by Timer's and Alarm's dials.
import { RING_FRACTION } from '../gesture-zones';

export const BAND_INNER_FRACTION = 0.6;

export function inBand(x: number, y: number, width: number, height: number): boolean {
  const r = Math.min(width, height) / 2;
  const d = Math.hypot(x - width / 2, y - height / 2);
  return d >= r * BAND_INNER_FRACTION && d <= r * (1 - RING_FRACTION);
}

/** The band as an SVG stroke in the 1000-unit disc: r 367.6, width 135.2. */
export function bandCircle(): { r: number; strokeWidth: number } {
  const inner = 500 * BAND_INNER_FRACTION;
  const outer = 500 * (1 - RING_FRACTION);
  return { r: (inner + outer) / 2, strokeWidth: outer - inner };
}

/** Degrees clockwise from 12 o'clock, in [0, 360). */
export function angleFrom12(x: number, y: number, cx: number, cy: number): number {
  return ((Math.atan2(x - cx, -(y - cy)) * 180) / Math.PI + 360) % 360;
}

/** The short way round, so crossing 12 is ±a few degrees, never ±360. */
export function unwrapDelta(fromDeg: number, toDeg: number): number {
  let d = toDeg - fromDeg;
  if (d > 180) d -= 360;
  if (d <= -180) d += 360;
  return d;
}
```

```ts
// The clock's alarms. Module scope because SwipeContainer unmounts the app on
// swipe-away; persisted so alarms survive restarts. Ringing them is the core
// alert layer's job (alarm-sync.ts keeps one alert per enabled alarm).
import { create } from 'zustand';
import { z } from 'zod';

export interface Alarm {
  id: string;
  /** 'HH:MM', 24-hour. */
  time: string;
  /** 0 Sunday … 6 Saturday; empty means once. */
  days: number[];
  enabled: boolean;
}

interface AlarmStore {
  alarms: Alarm[];
  add: (time: string, days: number[]) => string;
  update: (id: string, patch: Partial<Omit<Alarm, 'id'>>) => void;
  toggle: (id: string) => void;
  remove: (id: string) => void;
}

export const ALARM_STORAGE_KEY = 'superclock:app:alarm:v1';

const alarmSchema = z.object({
  id: z.string().min(1),
  time: z.string().regex(/^([01]\d|2[0-3]):[0-5]\d$/),
  days: z.array(z.number().int().min(0).max(6)),
  enabled: z.boolean(),
});

type StorageLike = Pick<Storage, 'getItem' | 'setItem'>;

const normalizeDays = (days: number[]) =>
  [...new Set(days)].filter((d) => Number.isInteger(d) && d >= 0 && d <= 6).sort((a, b) => a - b);

function load(storage: StorageLike | null): Alarm[] {
  if (!storage) return [];
  try {
    const raw = storage.getItem(ALARM_STORAGE_KEY);
    if (!raw) return [];
    const parsed = z.array(alarmSchema).safeParse(JSON.parse(raw));
    return parsed.success ? parsed.data : [];
  } catch {
    return [];
  }
}

const defaultId = () =>
  typeof crypto !== 'undefined' && 'randomUUID' in crypto
    ? crypto.randomUUID()
    : `a${Date.now().toString(36)}${Math.random().toString(36).slice(2, 8)}`;

export function createAlarmStore(storage: StorageLike | null, newId: () => string = defaultId) {
  const store = create<AlarmStore>()((set, get) => ({
    alarms: load(storage),
    add: (time, days) => {
      const id = newId();
      set({ alarms: [...get().alarms, { id, time, days: normalizeDays(days), enabled: true }] });
      return id;
    },
    update: (id, patch) =>
      set({
        alarms: get().alarms.map((a) =>
          a.id === id ? { ...a, ...patch, ...(patch.days ? { days: normalizeDays(patch.days) } : {}) } : a,
        ),
      }),
    toggle: (id) => set({ alarms: get().alarms.map((a) => (a.id === id ? { ...a, enabled: !a.enabled } : a)) }),
    remove: (id) => set({ alarms: get().alarms.filter((a) => a.id !== id) }),
  }));
  store.subscribe(({ alarms }) => {
    if (!storage) return;
    try {
      storage.setItem(ALARM_STORAGE_KEY, JSON.stringify(alarms));
    } catch {
      // Full or blocked storage: the alarms still ring this session.
    }
  });
  return store;
}

const defaultStorage =
  typeof window !== 'undefined' && window.localStorage ? window.localStorage : null;

export const useAlarms = createAlarmStore(defaultStorage);
```

```ts
// Pure time maths and labels for alarms. Occurrences are built from local date
// fields, so the Date constructor resolves DST (a 02:30 alarm on a
// spring-forward night rings at 03:30).
import type { Alarm } from './alarm-store';

export const DAY_LETTERS = ['S', 'M', 'T', 'W', 'T', 'F', 'S'] as const;
export const DAY_NAMES = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'] as const;

const pad = (n: number) => String(n).padStart(2, '0');

export function parseTime(time: string): { h: number; m: number } {
  const [h, m] = time.split(':').map(Number);
  return { h, m };
}

export function formatTime(h: number, m: number): string {
  return `${pad(h)}:${pad(m)}`;
}

export function clockText(epochMs: number): string {
  const d = new Date(epochMs);
  return formatTime(d.getHours(), d.getMinutes());
}

export function nextOccurrence(alarm: Alarm, now: Date): number | null {
  if (!alarm.enabled) return null;
  const { h, m } = parseTime(alarm.time);
  for (let d = 0; d <= 7; d++) {
    const c = new Date(now.getFullYear(), now.getMonth(), now.getDate() + d, h, m, 0, 0);
    if (c.getTime() <= now.getTime()) continue;
    if (alarm.days.length === 0 || alarm.days.includes(c.getDay())) return c.getTime();
  }
  return null;
}

export function nextAlarm(alarms: Alarm[], now: Date): { alarm: Alarm; at: number } | null {
  let best: { alarm: Alarm; at: number } | null = null;
  for (const alarm of alarms) {
    const at = nextOccurrence(alarm, now);
    if (at !== null && (!best || at < best.at)) best = { alarm, at };
  }
  return best;
}

export function daysLabel(days: number[]): string {
  const sorted = [...days].sort((a, b) => a - b);
  const key = sorted.join(',');
  if (sorted.length === 0) return 'Once';
  if (key === '0,1,2,3,4,5,6') return 'Every day';
  if (key === '1,2,3,4,5') return 'Weekdays';
  if (key === '0,6') return 'Weekends';
  return sorted.map((d) => DAY_NAMES[d]).join(', ');
}

export function untilLabel(ms: number): string {
  const totalMin = Math.max(1, Math.ceil(ms / 60_000));
  const d = Math.floor(totalMin / 1440);
  const h = Math.floor((totalMin % 1440) / 60);
  const m = totalMin % 60;
  if (d > 0) return `in ${d}d ${h}h`;
  if (h > 0) return `in ${h}h ${m}m`;
  return `in ${m}m`;
}

export function nextLabel(at: number, now: Date): string {
  const t = new Date(at);
  const dayDiff = Math.round(
    (Date.UTC(t.getFullYear(), t.getMonth(), t.getDate()) - Date.UTC(now.getFullYear(), now.getMonth(), now.getDate())) /
      86_400_000,
  );
  const when = dayDiff === 0 ? 'today' : dayDiff === 1 ? 'tomorrow' : DAY_NAMES[t.getDay()];

/** The ring dial: minutes move in 5-minute steps, hours in 1-hour steps, both wrapping. */

  const { h, m } = parseTime(time);
  if (mode === 'minutes') return formatTime(h, (((m + steps * 5) % 60) + 60) % 60);
```

```ts
// Keeps one core alert per enabled alarm, at its next occurrence. Started once
// at boot from index.ts. Subscriptions only, no timers: the core scheduler owns
// every boundary.
import {
  createAlertStore, useAlerts, type AlertState, type RingingAlert, type ScheduledAlert,
} from '../../core/alerts/alert-store';
import { loadLocalConfig, subscribeToConfig } from '../../shared/local-config';
import type { DeviceConfig } from '../../shared/types';
import { alarmAppSchema, type AlarmAppConfig } from '../../shared/schemas/app.alarm';
import { createAlarmStore, useAlarms, type Alarm } from './alarm-store';
import { nextOccurrence } from './alarm-schedule';

export const ALARM_RING_MS = 15 * 60_000;
export const alarmAlertId = (id: string) => `alarm:${id}`;
export const snoozeAlertId = (id: string) => `alarm:${id}:snooze`;

type AlertsApi = { getState(): AlertState };
type Unsub = () => void;

/** Alarm settings are device-wide: the first Alarm screen's config, else defaults. */
export function alarmSettings(config: DeviceConfig | null | undefined): AlarmAppConfig {
  const instance = config?.instances.find((i) => i.appId === 'alarm');
  const parsed = alarmAppSchema.safeParse(instance?.config ?? {});
  return parsed.success ? parsed.data : alarmAppSchema.parse({});
}

function alertFor(alarm: Alarm, firesAt: number, settings: AlarmAppConfig): ScheduledAlert {
  return {
    id: alarmAlertId(alarm.id),
    appId: 'alarm',
    firesAt,
    sound: settings.sound,
    bright: true,
    ringMs: ALARM_RING_MS,
    payload: { alarmId: alarm.id, time: alarm.time },
    ...(settings.gentleWakeMinutes > 0 ? { leadMs: settings.gentleWakeMinutes * 60_000 } : {}),
  };
}

function sameAlert(a: ScheduledAlert, b: ScheduledAlert): boolean {
  return (
    a.firesAt === b.firesAt &&
    a.sound === b.sound &&
    a.bright === b.bright &&
    a.ringMs === b.ringMs &&
    a.leadMs === b.leadMs &&
    a.payload.time === b.payload.time
  );
}

export function syncAlarmAlerts(alarms: Alarm[], alerts: AlertsApi, settings: AlarmAppConfig, now: Date): void {
  for (const alarm of alarms) {
    const at = nextOccurrence(alarm, now);
    if (at === null) {
      alerts.getState().cancel(alarmAlertId(alarm.id));
      continue;
    }
    const want = alertFor(alarm, at, settings);
    const have = alerts.getState().scheduled.find((a) => a.id === want.id);
    // An overdue alert (the clock was off or restarting at alarm time) is the
    // scheduler's to fire, so it rings or shows Missed; the ring then
    // schedules the next occurrence.
    if (have && have.firesAt <= now.getTime()) continue;
    if (!have || !sameAlert(have, want)) alerts.getState().schedule(want);
  }
  // A deleted alarm loses its alert and any pending snooze.
  const ids = new Set(alarms.map((a) => a.id));
  for (const a of alerts.getState().scheduled) {
    if (a.appId === 'alarm' && !ids.has(String(a.payload.alarmId))) alerts.getState().cancel(a.id);
  }
}

interface SyncDeps {
  alarms: ReturnType<typeof createAlarmStore>;
  alerts: ReturnType<typeof createAlertStore>;
  loadConfig: () => DeviceConfig | null;
  subscribeConfig: (listener: () => void) => Unsub;
  now: () => Date;
}

const defaultDeps: SyncDeps = {
  alarms: useAlarms,
  alerts: useAlerts,
  loadConfig: loadLocalConfig,
  subscribeConfig: subscribeToConfig,
  now: () => new Date(),
};

export function startAlarmSync(deps: SyncDeps = defaultDeps): Unsub {
  const run = () =>
    syncAlarmAlerts(deps.alarms.getState().alarms, deps.alerts, alarmSettings(deps.loadConfig()), deps.now());
  run();
  const offAlarms = deps.alarms.subscribe(run);
  const offConfig = deps.subscribeConfig(run);
  const offAlerts = deps.alerts.subscribe((s, prev) => {
    const r = s.ringing;
    if (!r || r.id === prev.ringing?.id || r.appId !== 'alarm' || r.id.endsWith(':snooze')) return;
    const alarmId = String(r.payload.alarmId);
    const alarm = deps.alarms.getState().alarms.find((a) => a.id === alarmId);
    // A once-alarm turns itself off (that re-syncs through the alarm store);
    // a repeating one gets its next occurrence now.
    if (alarm && alarm.enabled && alarm.days.length === 0) deps.alarms.getState().update(alarmId, { enabled: false });
    else run();
  });
  return () => {
    offAlarms();
    offConfig();
    offAlerts();
  };
}

export function snoozeAlarm(alert: RingingAlert, minutes: number, now: number, alerts: AlertsApi = useAlerts): void {
  const alarmId = String(alert.payload.alarmId);
  alerts.getState().dismiss();
  alerts.getState().schedule({
    id: snoozeAlertId(alarmId),
    appId: 'alarm',
    firesAt: now + minutes * 60_000,
    sound: alert.sound,
    bright: true,
    ringMs: ALARM_RING_MS,
    payload: { alarmId, time: alert.payload.time },
  });
}

/** Turning an alarm off or deleting it from the screen also drops its snooze. */
export function cancelSnooze(alarmId: string, alerts: AlertsApi = useAlerts): void {
  alerts.getState().cancel(snoozeAlertId(alarmId));
}

export function nextScheduledAlarm(scheduled: ScheduledAlert[]): number | null {
  let best: number | null = null;
  for (const a of scheduled) {
    if (a.appId === 'alarm' && !a.id.endsWith(':snooze') && (best === null || a.firesAt < best)) best = a.firesAt;
  }
  return best;
}
```

```tsx
import { useRef } from 'react';
import { angleFrom12, bandCircle, unwrapDelta } from '../../core/widgets/dial-geometry';

/** The invisible band that turns Alarm's ring dial. Only touches that start in
 *  the band claim the drag (data-gesture="claim"); it reports rotation in
 *  degrees and the screen turns that into 5-minute or 1-hour steps. */
export default function AlarmDial({ onRotate }: { onRotate: (deltaDeg: number) => void }) {
  const last = useRef<number | null>(null);
  const { r, strokeWidth } = bandCircle();

  const angleOf = (e: React.PointerEvent<SVGCircleElement>) => {
    const box = (e.currentTarget.ownerSVGElement ?? e.currentTarget).getBoundingClientRect();
    return angleFrom12(e.clientX, e.clientY, box.left + box.width / 2, box.top + box.height / 2);
  };

  return (
    <svg viewBox="0 0 1000 1000" className="absolute inset-0 h-full w-full" aria-hidden="true">
      <circle
        cx="500"
        cy="500"
        r={r}
        strokeWidth={strokeWidth}
        pointerEvents="stroke"
        data-gesture="claim"
        className="touch-none fill-none stroke-transparent"
        onPointerDown={(e) => {
          e.currentTarget.setPointerCapture?.(e.pointerId);
          last.current = angleOf(e);
        }}
        onPointerMove={(e) => {
          if (last.current === null) return;
          const deg = angleOf(e);
          onRotate(unwrapDelta(last.current, deg));
          last.current = deg;
        }}
        onPointerUp={() => {
          last.current = null;
        }}
        onPointerCancel={() => {
          last.current = null;
        }}
      />
    </svg>
  );
}
```

```tsx
  if (isActive !== wasActive) {
    setWasActive(isActive);
    if (isActive) setNow(Date.now()); // catch up after being swiped away
  }
  // The "in 8h 32m" line: once a minute, only while active (KIO-1).
  useEffect(() => {
    if (!isActive) return;
    const id = setInterval(() => setNow(Date.now()), 60_000);
    return () => clearInterval(id);
  }, [isActive]);

  // Resting ⇅ list through the shell's slot, HabitsApp's guarded shape.
  useEffect(() => {
    if (!isActive) {
      setVerticalSwipeCallback(null);
      return;
    }
    if (view.kind === 'edit') return;
    const cb = (dir: 'up' | 'down') => {
      if (dir === 'up' && view.kind === 'resting') setView({ kind: 'list' });
      else if (dir === 'down' && view.kind === 'list') setView({ kind: 'resting' });
      else if (dir === 'down') showGrid(); // swipe down at resting = the shell's default
    };
    setVerticalSwipeCallback(cb);
    return () => {
      // popLayout keeps the exiting app mounted after the next app registers;
      // only clear the slot if it is still ours.
      if (useNavigation.getState().verticalSwipeCallback === cb) setVerticalSwipeCallback(null);
    };
  }, [isActive, view.kind, setVerticalSwipeCallback, showGrid]);

  // The back gesture saves the alarm being edited, CalendarApp's guarded shape.
  useEffect(() => {
    if (!isActive || view.kind !== 'edit') return;
    const cb = () => {
      persistEdit(view);
      setView({ kind: 'list' });
    };
    setBackCallback(cb);
    return () => {
      if (useNavigation.getState().backCallback === cb) setBackCallback(null);
    };
  }, [isActive, view, setBackCallback]);

  const remainder = useRef(0);
  const startEdit = (alarm: Alarm | null) => {
    remainder.current = 0;
    setView({
      kind: 'edit',
      id: alarm ? alarm.id : null,
      time: alarm ? alarm.time : NEW_ALARM_TIME,
      days: alarm ? alarm.days : [],
      mode: 'minutes',
    });
  };

  if (view.kind === 'edit') {
    const rotate = (deltaDeg: number) => {
      const stepDeg = view.mode === 'minutes' ? 30 : 15; // 60 minutes or 24 hours a turn
      remainder.current += deltaDeg;
      const steps = Math.trunc(remainder.current / stepDeg);
      if (steps === 0) return;
      remainder.current -= steps * stepDeg;
      setView({ ...view, time: stepTime(view.time, view.mode, steps) });
    };
    const { h, m } = parseTime(view.time);
    const knob = ((view.mode === 'minutes' ? m * 6 : h * 15) * Math.PI) / 180;
    return (
      <div className="theme-fade relative flex h-full w-full items-center justify-center bg-(--face-bg)">
        <svg viewBox="0 0 1000 1000" className="pointer-events-none absolute inset-0 h-full w-full" aria-hidden="true">
          <circle cx="500" cy="500" r={R} strokeWidth="26" className="fill-none stroke-(--face-ghost)" />
          {Array.from({ length: 12 }, (_, i) => {
            const a = (i * 30 * Math.PI) / 180;
            return <circle key={i} cx={500 + 420 * Math.sin(a)} cy={500 - 420 * Math.cos(a)} r="5" className="fill-(--face-ink-muted)" />;
          })}
          <circle cx={500 + R * Math.sin(knob)} cy={500 - R * Math.cos(knob)} r="26" className="fill-(--color-accent)" />
        </svg>
        <AlarmDial onRotate={rotate} />
        <div className="relative flex flex-col items-center text-center">
          <button
            type="button"
            aria-label={view.mode === 'minutes' ? 'Switch the dial to hours' : 'Switch the dial to minutes'}
            onClick={() => {
              remainder.current = 0;
              setView({ ...view, mode: view.mode === 'minutes' ? 'hours' : 'minutes' });
            }}
            className="theme-fade text-[17vmin] leading-none tabular-nums text-(--face-ink)"
          >
            {view.time}
          </button>
          <p className="theme-fade mt-[1.5vmin] text-[2.2vmin] text-(--face-ink-muted)">
            {view.mode === 'minutes' ? 'Dial sets minutes · tap the time for hours' : 'Dial sets hours · tap the time for minutes'}
          </p>
          <div className="mt-[3vmin] flex gap-[1vmin]">
            {DAY_LETTERS.map((letter, d) => {
              const on = view.days.includes(d);
              return (
                <button
                  key={d}
                  type="button"
                  aria-pressed={on}
                  aria-label={DAY_NAMES[d]}
                  onClick={() => setView({ ...view, days: on ? view.days.filter((x) => x !== d) : [...view.days, d] })}
                  className={`theme-fade h-[5.6vmin] w-[5.6vmin] rounded-full text-[2.2vmin] ${
                    on ? 'bg-(--face-ink) text-(--face-bg)' : 'bg-(--face-ghost) text-(--face-ink)'
                  }`}
                >
                  {letter}
                </button>
              );
            })}
          </div>
          <p className="theme-fade mt-[1.5vmin] text-[2.2vmin] text-(--face-ink-muted)">
            {cfg.gentleWakeMinutes > 0
              ? `Gentle wake ${cfg.gentleWakeMinutes} min · snooze ${cfg.snoozeMinutes} min`
              : `Snooze ${cfg.snoozeMinutes} min`}
          </p>
          <div className="mt-[3vmin] flex gap-[2vmin]">
            <button
              type="button"
              onClick={() => {
                persistEdit(view);
                setView({ kind: 'list' });
              }}
              className="theme-fade rounded-full bg-(--face-ink) px-[3vmin] py-[1vmin] text-[2.6vmin] text-(--face-bg)"
            >
              Done
            </button>
            {view.id !== null && (
              <button
                type="button"
                onClick={() => {
                  const id = view.id as string;
                  cancelSnooze(id);
                  useAlarms.getState().remove(id);
                  setView({ kind: 'list' });
                }}
                className="theme-fade rounded-full border border-(--face-ghost) px-[3vmin] py-[1vmin] text-[2.6vmin] text-(--face-ink)"
              >
                Delete
              </button>
            )}
          </div>
        </div>
      </div>
    );
  }

  if (view.kind === 'list') {
    const sorted = [...alarms].sort((a, b) => a.time.localeCompare(b.time));
    return (
      <div className="theme-fade h-full w-full bg-(--face-bg) pt-[12vmin]">
        <RoundList<Alarm | typeof ADD>
          items={[...sorted, ADD]}
          header={<p className="theme-fade mb-[2vmin] text-[2.2vmin] text-(--face-ink-muted)">Alarms</p>}

            item === ADD ? (

                </span>

                  {item.time}
                </span>
                <Pills days={item.days} />

              </div>
            )
          }
        />
      </div>
    );

  if (alarms.length === 0) {
    return (
      <div className="theme-fade flex h-full w-full flex-col items-center justify-center bg-(--face-bg) text-center">
        <span className="flex h-[17vmin] w-[17vmin] items-center justify-center rounded-full border-2 border-(--face-ghost)">

          className="theme-fade mt-[1.5vmin] rounded-full border border-(--face-ghost) px-[3vmin] py-[1vmin] text-[2.6vmin] text-(--face-ink)"
        >
          Add alarm
        </button>
      </div>
    );
  }

  const next = nextAlarm(alarms, new Date(now));
  if (!next) {
    return (
      <div className="theme-fade flex h-full w-full flex-col items-center justify-center gap-[1.5vmin] bg-(--face-bg) text-center">
        <p className="theme-fade text-[2.6vmin] font-medium text-(--face-ink)">All alarms off</p>
        <p className="theme-fade text-[2.2vmin] text-(--face-ink-muted)">Turn one on in the list</p>
      </div>
    );
  }
  return (
    <div className="theme-fade flex h-full w-full flex-col items-center justify-center bg-(--face-bg) text-center">
      <p className="theme-fade text-[2.2vmin] text-(--face-ink-muted)">Next alarm</p>
      <span className="theme-fade mt-[1.5vmin] text-[17vmin] leading-none tabular-nums text-(--face-ink)">{next.alarm.time}</span>
      <p className="theme-fade mt-[1.5vmin] text-[2.6vmin] text-(--face-ink-muted)">{untilLabel(next.at - now)}</p>
      <Pills days={next.alarm.days} className="mt-[3vmin]" />
      <div className="mt-[3vmin] flex flex-col items-center gap-[1vmin]">
        <ArmedSwitch on label={`Alarm ${next.alarm.time}`} onToggle={() => toggleAlarm(next.alarm)} />
        <span className="theme-fade text-[2.2vmin] text-(--face-ink-muted)">Armed</span>
      </div>
    </div>
  );
}
```

```tsx
import type { AlertViewProps } from '../../core/alerts/views';

import { alarmSettings, nextScheduledAlarm, snoozeAlarm } from './alarm-sync';

const HOLD_MS = 2000;
const TAP_MS = 500;

/** Board frames 5, 6 and 8. With a speaker: the time inside two still accent
 *  rings (the chime is the alarm). Without: the full-screen flash and a chip.
 *  Tap to snooze; hold 2 s to stop. After 15 minutes: Missed. */
export default function AlarmAlert({ alert, phase, dismiss }: AlertViewProps) {
  const config = useDeviceConfig();
  const settings = alarmSettings(config);
  const speaker = deviceHasAudio(config?.deviceId);
  const nextAt = useAlerts((s) => nextScheduledAlarm(s.scheduled));
  const [renderNow] = useState(() => Date.now());
  const [holding, setHolding] = useState(false);
  const holdTimer = useRef<ReturnType<typeof setTimeout> | null>(null);
  const downAt = useRef(0);
  const time = String(alert.payload.time ?? '');

  if (phase === 'settled') {
    return (
      <button
        type="button"
        aria-label="Clear missed alarm"
        onClick={dismiss}
        className="theme-fade flex h-full w-full flex-col items-center justify-center bg-(--face-bg) text-center"
      >
        <span className="text-[2.6vmin] font-medium text-(--face-ink)">Missed</span>
        <span className="mt-[1.5vmin] text-[17vmin] leading-none tabular-nums text-(--face-ink-muted)">{time}</span>
        <span className="mt-[3vmin] text-[2.2vmin] text-(--face-ink)">

        <span className="mt-[1.5vmin] text-[2.2vmin] text-(--face-ink-muted)">Tap to clear</span>
      </button>
    );
  }

  const endHold = () => {
    if (holdTimer.current) clearTimeout(holdTimer.current);
    holdTimer.current = null;
    setHolding(false);
  };
  const onDown = () => {
    downAt.current = Date.now();
    setHolding(true);
    holdTimer.current = setTimeout(() => {
      holdTimer.current = null;
      setHolding(false);
      dismiss();
    }, HOLD_MS);
  };
  const onUp = () => {
    const pending = holdTimer.current !== null;
    const tap = Date.now() - downAt.current < TAP_MS;
    endHold();
    if (pending && tap) snoozeAlarm(alert, settings.snoozeMinutes, Date.now());
  };

  return (
    <button
      type="button"
      aria-label={`Alarm ${time}: tap to snooze, hold to stop`}
      onPointerDown={onDown}
      onPointerUp={onUp}
      onPointerLeave={endHold}
      onPointerCancel={endHold}
      className={`relative flex h-full w-full flex-col items-center justify-center text-center ${
        speaker ? 'theme-fade bg-(--face-bg) text-(--face-ink)' : 'alert-pulse'
```
